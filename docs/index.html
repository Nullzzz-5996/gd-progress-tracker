Весь прогресс в Geometry Dash в одном окне Every Geometry Dash run in one window

Читает прогресс прямо из файла сохранения игры, ведёт историю попыток по каждому уровню и строит графики набранных звёзд и демонов. Всё остаётся на твоём компьютере. Reads your progress straight from the game save, keeps a history of attempts for every level, and charts the stars and demons you have earned. Everything stays on your machine.

ВозможностиFeatures

Шесть вкладок, которые закрывают учёт прогресса Six tabs that cover the whole picture

Приложение написано на WPF под Windows и работает офлайн — интернет нужен только поиску уровней. A native WPF app for Windows that works offline — only level search needs the internet.

УровниLevels

Полный список уровней с процентом прохождения, сложностью, звёздами и числом попыток. Фильтр по названию, автору, сложности и ID. The full list of levels with completion percentage, difficulty, stars and attempt count. Filter by name, creator, difficulty or ID.

ПрогрессыProgress log

Отдельная вкладка для записи каждой попытки: процент, дата, заметка. Видно, как уровень поддавался со временем. A dedicated tab to log each run: percentage, date, note. Watch a level give in over time.

СтатистикаStats

Сводка по аккаунту и графики динамики: сколько звёзд и демонов набрано и в какой момент это произошло. An account summary plus trend charts: how many stars and demons you earned, and exactly when.

Поиск онлайнOnline search

Найти уровень на серверах Geometry Dash по названию или ID и добавить в свой список — прогресс подтянется из сейва автоматически. Find a level on the Geometry Dash servers by name or ID and add it to your list — progress is pulled from your save automatically.

CPS-тестCPS test

Замер кликов в секунду с перехватом ввода на уровне системы — клики считаются, даже когда окно приложения не в фокусе. Clicks per second measured with system-level input hooks — clicks count even when the window is not focused.

Импорт и обменImport & sharing

Читает CCGameManager.dat напрямую. Экспорт и импорт файлов, чтобы делиться прогрессом с друзьями. Reads CCGameManager.dat directly. Export and import files to share your progress with friends.

Как начатьGetting started

Три шага до первого импорта Three steps to your first import

1

Скачай и распакуйDownload and unpack

Установщик не нужен — распакуй архив в любую папку и запусти GdTracker.App.exe. No installer needed — unpack the archive anywhere and run GdTracker.App.exe.

2

Укажи путь к сейвуPoint it at your save

На вкладке «Уровни» проверь путь к CCGameManager.dat — обычно он лежит в %LOCALAPPDATA%\GeometryDash\. On the Levels tab, check the path to CCGameManager.dat — it usually lives in %LOCALAPPDATA%\GeometryDash\.

3

Нажми «Импорт из игры»Hit “Import from game”

Все уровни с прогрессом появятся в списке. Импорт можно повторять сколько угодно — записи, добавленные вручную, он не трогает. Every level with progress lands in the list. Re-run the import as often as you like — entries you added by hand are left alone.

Данные остаются у тебя Your data stays yours

Ни аккаунта, ни регистрации, ни телеметрии. Файл сохранения игры открывается только на чтение — приложение в него не пишет. No account, no sign-up, no telemetry. The game save is opened read-only — the app never writes to it.

Единственный сетевой запрос — поиск уровней на серверах Geometry Dash, и только когда ты сам его запускаешь. Логин в игровой аккаунт не требуется. The only network request is level search against the Geometry Dash servers, and only when you run it yourself. No game-account login required.
